Instalação rápida

cd Jarvis
python -m pip install -r requirements.txt
ollama pull qwen2.5-coder:7b
python jarvis.py

Padrão: modo escrita (só teclado). Para microfone, digite modo escuta.

O que inclui

  • Núcleo jarvis.py e módulos (voz, bandeja, autoaperfeiçoamento, avançados)
  • Modo escrita padrão + modelo de programação

  • Documentação unificada no README e licença completa de usos
