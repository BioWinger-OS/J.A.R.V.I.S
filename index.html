Recursos principais

Módulos reais do pacote — voz, automação, memória e expansão contínua.

Reconhecimento de Voz Adaptativo

Embeddings personalizados (.npy), banco de amostras do dono e limiar dinâmico para aceitar só a sua voz.

Autoaperfeiçoamento

Às 15h pesquisa temas de programação, grava conhecimento JSON e gera propostas seguras — sem reescrever o núcleo sozinho.

Bandeja do Sistema

Roda em segundo plano na tray do Windows, troca modo escrita/escuta e inicia com o sistema via atalho.

Plugins & Hot-Reload

Pasta plugins/ para scripts novos. Recarregue em tempo real com o comando recarregar plugins.

Automação & Workspaces

Mídia, volume, clipboard, organizador de D:\downloads, modo dev e hotkey global Ctrl+Shift+J.

RAG & Conhecimento

Indexe PDFs e anotações em docs_rag/, pergunte aos seus docs e mantenha perfil em JSON local.

Estrutura do projeto

Pacote unificado — um único core Python.

Jarvis / explorador
  • Jarvis/
  • ├── Iniciar_Jarvis.vbs — atalho sem console
  • ├── jarvis.py — núcleo + todos os recursos
  • ├── requirements.txt
  • ├── README.md · LICENSE
  • ├── conhecimento/ — perfil, regras, foco
  • ├── memory/ — memoria.json, propostas
  • ├── plugins/ — ativos.json + seus scripts
  • ├── voices/ — embeddings .npy + config
  • ├── docs_rag/ — PDFs e notas para RAG
  • └── index.html — esta landing page

Como instalar

Três passos. Modelo padrão: qwen2.5:7b via Ollama.

1

Python 3.10+ e Ollama

Instale Python no PATH e o Ollama. Depois: ollama pull qwen2.5:7b

2

Dependências

terminal 
pip install -r requirements.txt
3

Iniciar

Execute Iniciar_Jarvis.vbs (segundo plano) ou python jarvis.py no terminal.

Baixar pacote completo
